Smart Productivity SuiteA high-performance, feature-rich productivity application designed to help you manage tasks, track goals, and maintain a consistent workflow.🚀 Key Features•Smart Dashboard: Real-time progress tracking with circular visualization.•Intelligent Reminders: Browser-based notifications for time-sensitive tasks.•Recurring Tasks: Support for daily and weekly task generation.•Advanced Organization: Categorize tasks (Work, Study, Personal) and set priority levels.•Dynamic Views: Switch between Today, Upcoming, and Analytics views.•Dark Mode: Fully integrated dark theme for late-night productivity.•Responsive Design: Optimized for both desktop and mobile devices.🛠️ Tech Stack•HTML5: Semantic structure for accessibility.•CSS3: Custom properties, Flexbox/Grid, and smooth animations.•JavaScript (ES6+): Object-oriented architecture for state management.•Local Storage: Persistent data storage without a backend.•Notification API: Native browser integration for reminders.📖 How to Run
